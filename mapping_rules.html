4. 김포 조회 규칙 (getGimpoQty)

4-1. 자체코드 규칙 (단품)

  1. 규칙키 후보: 원본 → _AL 제거 → _SET/-SET/_nSET 제거 → - 앞 → _ 앞
  2. setRuleMap 첫 일치 규칙 사용
  3. 옵션 색상:사이즈 파싱 (55:블랙도 인식)
  4. 색상코드 = 규칙 colorMap → 전역 COLOR_MAP → 원문
  5. gpPrefix-색상-사이즈 조회. 없으면 재고 0 (매핑없음으로 안 떨어짐)
JW25SS01_AL / 플림:55 → 규칙 JW25SS01 → 플림=PL → 252JW07-PL-55

4-2. 세트 옵션 (+)

  • 각 색상 코드화 → 구성 SKU들 · 같은 색 N개면 재고 ÷ N (내림)
  • 세트 재고 = 구성별 (재고÷필요수)의 최솟값 · 구성 하나라도 없으면 매핑없음
플럼+베이지:55 → min(BU-55, BE-55)
플럼+플럼:55   → floor(PL-55 / 2)

4-3. 저장 매핑

  1. 물류품번 = 코드 고정맵 → 대시보드 수정분 → aspro_match (__DELETED__=삭제)
  2. 없으면 정규화 상품명+옵션 이름매핑
  3. 품번 변경 자동변환 252MX18-001~016 → 252MX18CD-001~016
  4. 없으면 구패턴→신패턴 재시도 → 그래도 없으면 이카운트 품목명 [색상/사이즈]로 찾기 → 없으면 김포 0
  5. 같은 물류품번·같은 사이즈에 옵션 N개 매핑 → 재고 ÷ N 김포(÷N)

5. 이카운트 조회 규칙 (getIcountQty)

색상/사이즈는 이카운트 품목명의 [색상/사이즈]에서 읽음 (-공통 제거)

순위방법
0고정값 DIRECT_QTY_MAP (102579-0001 → N1009-009 = 26)
1직접매핑: aspro_iccodemap → IC_STATIC_MAP → 세트면 setmap prefix
2자체코드 / SAB_IC_OVERRIDE / -앞 / 끝 색상코드 제거
3이름매칭: 정규화 상품명 일치 → 키워드 교집합

결과 판정

  • 세트: 구성 모두 있으면 min → 이카운트(세트), 없으면 직접매핑 세트품절 / 이름매칭 매핑없음
  • 색상+사이즈 일치 → 이카운트
  • 직접매핑인데 사이즈 없음 → 자동품절 · 사이즈 있고 색상 없음 → 컬러불일치
  • 이름매칭 불일치 → 매핑없음 (오매칭 방지)
  • 사이즈만 있는 옵션: 1건 그대로 / 여러 건 합산 이카운트(합산)
  • 사이즈만 있는 _SET (예 N1008_SET / 55): setmap 색상 전체를 구성으로 세트 계산

IC_STATIC_MAP 예: JW25SS01*→252JW07 · JW25SS02*→252JW19 · H1014*→H1014 · 251JW_AL→251JW · 252JW10*→252JW10 · NT244G0069-73JK→244NT69

저장된 상품 정체성만 재사용. 이름 유사도·같은 사이즈만으로 연결 금지.
  1. 강제품절·강제재고·품절처리·발주서품절은 자동 판매 제외 → 검수

  5. 그 외 prefix 안 색상+사이즈 일치가 정확히 1건일 때만 연결

최종 검증 · 안전장치

  • 판매 인정 조건: 이카운트 소스 · 모든 코드가 원본 존재 · 재계산 수량과 정확히 일치 · 자동품절류 아님
  • 아니면 unmatched → 사방넷 전송 제외 (0으로 보내지 않음)
  • 중단 조건: 사방넷 옵션 <3,000 · 이카운트 코드 <1,500 · 평일 당일 원본 아님 · 결과 상품 <400

8. 사방넷 내보내기 (대시보드)

  • 수량 = matched면 재고, 그 외 0
  • 안전재고: floor(재고 × 70%) → 0 < 값 < 5 면 0 (둘 다 변경 가능)
  • F열 가상재고 = 수량 · G열 공급상태 = 수량>0 ? 1(판매) : 2(품절)

  • 무효 물류품번 제거: 빈값, 0, 5자리 숫자, #N/A, 품절, 확인요망, 슈컴퍼니…, 김포재고O…, 삭제요청…, ???, 중복, 위에
  • 사방넷에 없는 코드 매핑은 정리하되 _SET 코드는 보호
